Using ComputerJailbreak

This guide will help you jailbreak with ComputerJailbreak. ComputerJailbreak is a jailbreak for iOS 0.0-0.0.0.

Downloads

  • The latest version of ComputerJailbreak
  • The latest version of iTunes if on Windows

Steps

  • If you're on Mac, the file will be called "ComputerJailbreak"<./li>
  • If you're on Windows, the file will be called "ComputerJailbreak.exe".
  1. Plug in your device.
  2. Open the ComputerJailbreak file.
  3. Press "Jailbreak".

ComputerJailbreak should start jailbreaking.

You should now be jailbroken with ComputerJailbreak. You should also have Package Manager on your device.
