Using Aquila

This guide will help you jailbreak with Aquila. Aquila is an untethered jailbreak for iOS 4.3-7.0.6.

Aquila is untethered, meaning you only run the exploit once!

Downloads

  • The latest version of Aquila
  • The latest version of iTunes if on Windows

Steps

  • If you're on Mac, the file will be called "aquila"<./li>
  • If you're on Windows, the file will be called "aquila_windows.exe".
  1. Plug in your device.
  2. Open the Aquila file.

Aquila should start jailbreaking.
